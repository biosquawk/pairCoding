# Puzzle 7: Swap Meat

Temat: Kolejność ewaluacji i XOR.

Czy jedna linia naprawdę zamienia zmienne? Przewidź obie końcowe wartości i opisz, kiedy Java zapamiętuje lewy operand zewnętrznego przypisania. Zaproponuj prostą zamianę z lokalną zmienną.

1. Otwórz `Puzzler.java` i przeanalizuj `observed()` bez uruchamiania.
2. Zastąp `TODO` w `prediction()` dokładnym przewidywanym tekstem. Nie zmieniaj `observed()` ani testów.
3. Dodaj pod metodą krótki komentarz wyjaśniający typy lub kolejność obliczeń.
4. Użyj Run Main, porównaj przewidywanie z obserwacją i uruchom Run Tests.

Pierwszy Run Tests ma być czerwony, dopóki nie uzupełnisz przewidywania. Testy sprawdzają tekst i niezmieniony demonstrator; nie oceniają jakości pisemnego wyjaśnienia. Poproś trenera o omówienie tego wyjaśnienia. To ćwiczenie z przewidywania działania Javy, a nie poprawiania demonstratora pod test.
