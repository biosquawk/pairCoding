# Utwórz zasób przez POST

POST /items z JSON {"name":"alpha"} ma zwrócić 201, Location: /items/1 i reprezentację zasobu z przekazaną nazwą. Niepoprawny JSON daje 400. Starter myli status utworzenia. Popraw kontrakt HTTP.

Profil: java-maven-21. POM i testy są częścią kontraktu; nie zmieniaj zależności.

Materiał: http-contract. Autorskie opracowanie, nie książka użytkownika.
