# 3/5 · Połącz dwa wyniki · 6 min

BEGINNER. Dwa obliczenia już działają w puli. `thenCombine` otrzymuje ich wyniki jako
`left` i `right`, gdy oba są gotowe. Starter ignoruje drugi wynik.

**Twoja zmiana (1 wyrażenie):** w lambdzie zwróć sumę `left` i `right`.
Nie zastępuj pracy pulą liczb na sztywno. Run Main: `Suma: 42`; Run Tests: PASS.
Test kontrolny przekazuje też wartości ujemne i niedokończony drugi wynik.
API pochodzi z Java 8; runtime nadal Java 21. Po PASS wybierz **Dalej**.
